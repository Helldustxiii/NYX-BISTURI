# 🌱 JARDÍN NYX / BISTURÍ

Espacio de continuidad, evolución y registro del sistema NYX / BISTURÍ.

## Principio

> Primero entender y después actuar.

## Función

El Jardín conserva aquello que merece continuidad:
- aprendizajes;
- decisiones;
- evolución de arquitectura;
- principios operativos;
- registros relevantes;
- raíces simbólicas y criterios que modifican la continuidad del sistema.

No todo debe conservarse. El criterio decide qué permanece.

## Estructura vigente

Los registros nuevos se almacenan en `JARDIN/registros/`, organizados por fecha.

Formato:

`JARDIN/registros/NYX_BISTURI_Jardin_AAAA-MM-DD.md`

Esta ruta es la convención documental vigente desde el 2026-11-15. No implica que los registros históricos se hayan movido.

## Archivo histórico

La organización inicial produjo rutas profundamente anidadas y referencias de ubicación inconsistentes. Los originales se conservan donde Git los registra; no deben trasladarse ni sobrescribirse como parte de una limpieza rutinaria.

Consulta el [índice histórico del Jardín](INDICE-HISTORICO.md) para la cronología, las rutas heredadas, la evolución conceptual y los límites de la reconstrucción.

## Criterio de mantenimiento

- Conservar los originales históricos.
- Añadir registros solo cuando exista aprendizaje, decisión o cambio con continuidad.
- Distinguir hechos, inferencias e hipótesis.
- No convertir el Jardín en una transcripción de conversaciones.
- Mantener separadas la memoria histórica, la documentación operativa y el estado de implementación.
